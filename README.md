# MONOBLOCK / ARC — REV.03

Стереомоноблок с дугой верхней/нижней крышек, отдельными наклонными фронтальными панелями и семью активными каналами.

- Бас сзади: Dayton RSS265HF-4; пассивник спереди: RSS315-PR.
- Основные L/R: SB15NBAC30-8 + SB26ADC-C000-4, разворот внутрь 8°.
- Наружная пара на фронте: Scan-Speak 10F/4424G00, разворот наружу 35°.
- miniDSP Flex Eight, 3 × Fosi V3 stereo + V3 Mono; внешние блоки питания, UMIK-1 для настройки.

```sh
npm ci
npm run dev
npm test
npm run build
```

Габарит дерева **1360 × 420 × 470 мм**, с опорами высота 450 мм. Дуга R 1843,46 мм, стрела 130 мм. Верх/низ по 36 мм. Чистые расчётные объёмы: **46,034 + 2 × 5,151 + 2 × 0,683 л**.

- `src/config.js` — единые размеры, повороты, головки, источники, вычеты объёмов, распил и карта DSP.
- `src/acoustics.js` — настройка PR, закрытые камеры и связанная НЧ-модель с ходом, защитным ФВЧ и отключаемой пробной EQ.
- `src/cabinet.js` — дуговые крышки, отдельные герметичные камеры, посадки, распорки, решётка и ориентировочная электроника.
- `public/engineering.md` — актуальный расчёт, допущения, монтаж и порядок доводки.
- `public/drawings.svg` — самостоятельный векторный чертёж с видами сверху/спереди/сзади и посадочными габаритами.
- `public/components.json` — актуальная спецификация и маршрутизация для экспорта.
- `docs/component-proposal.md` — история подбора до реализации, не действующий источник размеров.
- `npm run docs` — обновляет все три генерируемых документа; входит в сборку.

Масса деревянных панелей около **55 кг** при принятой плотности 650 кг/м³, без головок и электроники. Текущий вариант со сплошными крышками тяжёлый; консоль должна выдерживать итоговую нагрузку.

В интерфейсе доступны корпус, вскрытый корпус, разборка, чертёж, решётка и оси излучателей. «Акустика» показывает отклик и ход при изменении напряжения, ФВЧ и пробной коррекции. «Сборка» содержит головки, восемь выходов DSP (семь используются), распил TSV и источники.

При 20 В RMS, ФВЧ LR4 22 Гц и настройке PR 28 Гц модель даёт F3≈34,5 Гц; с пробным peak EQ +3 дБ / 30 Гц / Q1 — около 29,8 Гц. Это линейный расчёт относительно 100 Гц, без разделительного ФНЧ, комнаты, разности пути и нелинейностей; не измеренная АЧХ. Нужный добавочный груз PR около 97 г уточняется по импедансу.

Размеры проёмов, стыки наклонных панелей, вычеты объёмов (кроме паспортных 0,05 л у 10F), крепёж и тепловая компоновка требуют проверки на физических деталях. Чертёж не является CAM-файлом. Визуальные стрелки — геометрические оси, не расчёт акустической направленности. Настройки основных полос и наружных каналов доводятся измерениями; пробная задержка 4 мс не означает гарантированного расширения сцены.
